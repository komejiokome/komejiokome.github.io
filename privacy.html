Privacy Policy

Last updated: September 28, 2026

This policy describes the optional YouTube upload feature of INFINITAS Playlog Viewer.

Google user data accessed

The application uses Google OAuth 2.0 and requests the YouTube upload permission (youtube.upload) so it can upload recordings to the Google account explicitly authorized by the user.

How data is used

The permission is used only to upload local recording files from the application's configured recording folder to the user's own YouTube account. Uploads made by this feature are created as private videos.

Storage

OAuth credentials and refresh tokens are stored locally on the user's computer. Play-history data and recording files are read from local paths configured by the user. The developer does not operate a remote backend that collects these files or tokens.

Sharing

The application does not sell Google user data and does not share Google user data with advertisers or unrelated third parties. Recording files are transmitted to YouTube only when the upload feature is used.

Retention and deletion

Local OAuth tokens remain on the user's computer until removed by the user or the application's local state is deleted. Videos uploaded to YouTube are governed by the user's YouTube account settings and can be deleted by the user through YouTube. OAuth access can also be revoked from the user's Google Account permissions.

Limited use

Use of information received from Google APIs is limited to providing the user-facing upload functionality described above and is intended to comply with the Google API Services User Data Policy, including its Limited Use requirements.
